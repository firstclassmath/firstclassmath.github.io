# 11/28 상담 예약 — 구글 시트 연결 방법

예약 페이지(`booking/index.html`)는 구글 시트에 예약을 저장한다. 아래를 한 번만 하면 된다(약 10분).
예약자 이름·연락처는 **구글 시트에만** 저장되고, 이 저장소(공개)에는 들어가지 않는다.

## 1. 시트 만들기
1. 구글 드라이브에서 새 스프레드시트를 만든다. 이름 예: `11-28 상담 예약`.
2. 공유 설정은 바꾸지 않는다(나만 보기). 웹 앱이 내 권한으로 대신 기록한다.

## 2. 스크립트 붙여 넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script**.
2. `Code.gs`의 내용을 모두 지우고 `booking/apps_script.gs` 내용을 붙여 넣은 뒤 저장(Ctrl+S).
3. 정원을 바꾸려면 맨 위 `const CAP = 1;` 을 고친다. 강사 2명이 같은 시간에 따로 상담하면 `2`.
4. 위쪽 함수 선택 칸에서 `testMail` 을 고르고 **실행** → 권한 승인(아래 3-3과 같은 경고). 내 Gmail로 시험 메일이 오면 알림 준비 끝.
   - 알림은 스크립트를 만든 구글 계정으로 간다. 다른 주소로 받으려면 **편집기 안에서만** `const NOTIFY = '';` 에 주소를 넣는다(저장소 파일에는 넣지 않는다 — 공개됨).

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택.
2. 실행 사용자: **나**, 액세스 권한이 있는 사용자: **모든 사용자**.
3. **배포** → 권한 승인(내 구글 계정 선택 → "고급" → "안전하지 않은 페이지로 이동" → 허용). 내가 만든 스크립트라서 나오는 경고다.
4. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.
5. 확인: 그 URL을 브라우저 주소창에 열면 `{"ok":true,"cap":1,"counts":{"10:00":0,…,"13:30":0}}` 가 보이고, 시트에 `예약` 탭이 생긴다.

## 4. 예약 페이지에 주소 넣기
`booking/index.html` 아래쪽 `<script>` 첫 줄:
```js
const API = "";   // ← 따옴표 안에 웹 앱 URL 붙여 넣기
```
저장 → commit → push. 주소가 비어 있으면 페이지에 "온라인 예약 준비 중"이 뜨고 예약 버튼이 막힌다.

## 운영 메모
- 예약은 시트 `예약` 탭에 한 줄씩 쌓인다. 취소는 그 줄을 **삭제**하면 시간이 다시 열린다.
- 같은 연락처로 두 번 예약할 수 없다(변경은 전화로 안내).
- 새 예약이 들어오면 알림 메일이 온다(제목: `[11/28 상담 예약] 11:00 학생이름`).
- 완료 화면에서 학부모에게 카톡 채널 1:1 채팅으로 **예약번호**(예: `1128-1100`)를 보내 달라고 안내한다. 카톡이 오면 확정 안내를 하고, 오지 않으면 전화로 확인한다. 연락이 닿지 않는 예약은 시트에서 줄을 지워 시간을 다시 연다.
- 스크립트를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 반영된다. URL은 그대로다.
- 상담이 끝나면 시트의 예약자 정보를 삭제한다(페이지에 "상담 후 삭제"라고 안내함).
- 로컬 시험: `booking/index.html?mock` 으로 열면 서버 없이 가짜 데이터로 동작한다.
